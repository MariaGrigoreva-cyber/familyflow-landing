# Семейный поток — лендинг

Маркетинговый лендинг (myfamilyflow.ru). Статическая страница (HTML/CSS/JS без сборки), `server.js` — простая раздача файлов через Express для деплоя на Timeweb App Platform (build: `npm install`, run: `npm start`).

Дизайн воссоздан по хендофф-пакету `design_handoff_familyflow_landing/` (см. README там — точные цвета/отступы/тексты).

Ссылки «Открыть приложение» ведут на `https://app.myfamilyflow.ru` — само приложение (React PWA, репозиторий `Familyflow`) переносится на этот поддомен отдельно.
